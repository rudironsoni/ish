# ish-app-runtime-audit

Audit iSH app launch, shell mode, and runtime milestone truth.

## Use when

- checking app launch readiness
- checking terminal UI reachability
- distinguishing `task_zero` from `full_guest`
- checking milestone truth for app cases

## MUST verify

- app shell status
- guest-enabled versus guest-disabled mode
- current runtime scope
- current milestone ceiling
